# Raccourcis clavier

## Fenêtre principale

| Raccourci | Action |
|---|---|
| Ctrl+N | Nouveau projet |
| Ctrl+O | Ouvrir un projet |
| Ctrl+S | Enregistrer |
| Ctrl+Maj+S | Enregistrer sous… |
| Ctrl+E | Exporter le rapport en Markdown |
| Ctrl+Maj+P | Exporter le rapport en PDF |
| Ctrl+Maj+W | Exporter le rapport en Word (.docx) |
| Ctrl+Q | Quitter |
| **F1** | Ouvrir l'aide à la rubrique de la page affichée |
| F11 | Plein écran (menu *Affichage*) |
| Ctrl+1 … Ctrl+7 | Aller au groupe de pages : Général, Atelier 1 à 5, Rapport (menu *Ateliers*) |

## Dans les tableaux

| Action | Comment |
|---|---|
| Éditer une cellule de texte | Double-clic ou F2 |
| Éditer un texte long | Double-clic (boîte de dialogue) |
| Valider / annuler la saisie | Entrée / Échap |
| Sélection multiple de lignes | Ctrl+clic, Maj+clic |
| Se déplacer de cellule en cellule | Flèches, Tab |

## Dans la fenêtre d'aide

| Raccourci | Action |
|---|---|
| Ctrl+F | Aller au champ Rechercher |
| Entrée ou F3 | Occurrence suivante |
| Boutons ◀ ▶ | Occurrence précédente / suivante |
| Boutons « Rubrique précédente / suivante » | Naviguer dans les rubriques visibles |
