Conçu pour votre poste de travail

Une application de bureau multiplateforme.

EBIOS RM Studio s'appuie sur Qt 6 et C++17. Le projet est conçu pour être compilé sous Linux et Windows.

▣

Windows

Compilation possible avec Visual Studio (MSVC) ou MinGW, avec déploiement des dépendances Qt prévu dans le processus de build.

⌘

Linux

Compilation documentée pour les distributions Linux, notamment Debian, Ubuntu et Fedora.

◇

Format de projet ouvert

Les études sont enregistrées au format .ebios, un fichier JSON lisible. Un outil permet également d'importer un classeur Excel compatible.
